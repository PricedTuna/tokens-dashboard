# Skill Registry

## Project Standards

- **Tech Stack**: Vite, React, Vanilla CSS.
- **Goal**: Create a premium, aesthetic dashboard for token comparison.
- **Rules**:
  - Use Vanilla CSS (glassmorphism, vibrant colors).
  - Prioritize TRON, TOON, JTON comparison.
  - Highlight totals clearly.
  - Desktop-first design.
